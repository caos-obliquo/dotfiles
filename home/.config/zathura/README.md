# zathura

PDF/document viewer. Dracula-themed.

## Files

- `zathurarc` — colors, clipboard selection

## Keybinds (defaults)

| Key | Action |
|---|---|
| `j/k` | scroll down/up (vim grammar) |
| `Ctrl+O` | open file |
| `Tab` | toggle index |
| `F` | fullscreen |

## Notes

- Selection copies to the clipboard directly (`selection-clipboard`).
- Window title shows the basename.
