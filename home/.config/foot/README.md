# foot

Wayland terminal emulator. Dracula-themed, transparent.

## Files

- `foot.ini` — font, colors, transparency

## Keybinds (defaults)

| Key | Action |
|---|---|
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | copy / paste |
| `Ctrl+Shift+U` | unicode input |
| `Ctrl+Shift+Up/Down` | font size |
| `Ctrl+Shift+R` | reload config |

## Notes

- Font: JetBrainsMono Nerd Font 10, `dpi-aware=yes`.
- Alpha 0.85 — true transparency via the compositor.
- Launched with `Super+Shift+Return` (dwl).
